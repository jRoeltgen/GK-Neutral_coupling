\section{File extensions for Eirene sources}
All files are of the form fort.???. The first ? specifies the type of source (particle, momentum, or energy). The second ? specifies the type of collision (atom-plasma, molecule-plasma, test ion-plasma, photon-plasma, plasma-plasma/primary source). The third ? specifies the species type it is a source for.
